# ASTRO-ANALYZER v1.0.0

**ASTRO-ANALYZER** — это программа для автоматической сегментации и морфометрии астроцитов, нейронов и клеток микроглии на 3D-стеках и 2D-изображениях, полученных методами конфокальной и эпифлуоресцентной микроскопии (срезы ткани либо культура клеток). 

Результатом работы является таблица морфологических параметров каждой клетки: объём сомы, объём ядра, объём всей клетки с отростками, площади проекций, средние интенсивности, элонгация, ядерно-цитоплазматическое отношение, сложность ветвления отростков и другие признаки.

---

## I. ПАЙПЛАЙН

Для каждого входного файла (.tif / .nd2 / .czi / .lif / .ome.tif / .oir / .oif стек) программа выполняет следующие шаги:

1. Читает изображение и метаданные (масштаб XY и Z, каналы, оптические параметры).
2. Проводит 3D-деконволюцию (если включено пользователем) для подавления внефокусного свечения.
3. Просит пользователя расставить центры сом на проекции максимальной интенсивности (MIP) или находит их автоматически (Beta).
4. Автоматически очерчивает сому каждой размеченной клетки в 3D.
5. Автоматически находит ядро каждой клетки в DAPI-канале.
6. Выращивает всю клетку (сома + отростки) в канале клеток.
7. Даёт возможность вручную исправить или удалить проблемные клетки (если включена ручная фильтрация).
8. Считает морфологические параметры каждой клетки и сохраняет их в формате CSV.
9. Генерирует визуализации масок каждой клетки.
10. Складывает результаты из всех файлов данной папки в общий накопленный CSV.

## III. ИНТЕРФЕЙС

Главное окно программы разделено на две части:

- **Слева — рабочая область.** В режиме настроек здесь отображается панель параметров. После запуска анализа здесь появляется протокол работы (лог). Между экраном настроек и логом можно свободно переключаться кнопками «← Настройки» (в логе) и «→ Вернуться к логу» (в настройках).
- **Справа — панель диалога.** Здесь появляются все всплывающие панели (выбор каналов, расстановка сом, ручная фильтрация и т.д.). Инструкции по работе с каждой панелью выводятся в нижней её части.

### Панель настроек включает следующие поля:

- **Файл/папка.** Интерактивный выбор файла или папки для анализа («Обзор…»).
- **Режим загрузки.** «Один файл» (для анализа одного стека / снимка) или «Папка» (для анализа папки с несколькими файлами).
- **Метаданные.** Кнопка «Прочитать из файла» пробегает по выбранному файлу и заполняет поля ниже (масштаб XY/Z, оптические параметры клеток и DAPI). Если метаданных нет — поля остаются с дефолтами.
- **Тип клеток.** «Астроциты», «Микроглия» или «Нейроны». Влияет на имя выходной папки и отображаемое название в логе.
- **Тип изображения.** «Конфокальный» или «Эпифлуоресцентный». Определяет, какой препроцессинг будет применяться перед сегментацией (grain index для конфокала, LoG с гамма-коррекцией для эпифлуоресценции).
- **Деконволюция.** Включает/выключает 3D-деконволюцию в протоколе препроцессинга.
- **XY (мкм/пиксель), Z (мкм/срез).** Определяют физический масштаб, от которого зависят все объёмные и линейные измерения.
- **Клетки: NA, λ, ε.** Параметры оптики для деконволюции канала клеток (числовая апертура, длина волны эмиссии, регуляризация Винера).
- **DAPI: NA, λ, ε.** Параметры оптики для деконволюции канала DAPI.
- **Гранулы: NA, λ, ε.** Параметры оптики для деконволюции канала гранул (если используется).
- **Автодетекция сом.** Включает автоматический поиск сом (Beta).
- **Ручная фильтрация клеток.** Включает запуск диалога ручной правки после автоматической сегментации.
- **Метрики…** Открывает окно выбора метрик, которые попадут в CSV.

Для запуска анализа нажмите **«▶ Запустить анализ»**. Для выхода — **«Выход»**. Переключение языка (RU/EN) доступно в правом верхнем углу.

## IV. ПОРЯДОК РАБОТЫ

1. Нажмите «Обзор…» и выберите файл или папку.
2. При необходимости нажмите «Прочитать из файла», чтобы подтянуть метаданные.
3. Убедитесь, что **Тип изображения** соответствует вашим данным.
4. Выберите **Тип клеток**.
5. Оставьте остальные параметры по умолчанию либо настройте их вручную.
6. Нажмите **«▶ Запустить анализ»**.
7. Пройдите ручные диалоги (см. ниже).
8. По окончании работы смотрите результаты в папке <имя_файла>_<тип_клеток>_analysis/.

## V. ЭТАПЫ ОБРАБОТКИ ФАЙЛА ПОСЛЕ НАЖАТИЯ «▶ ЗАПУСТИТЬ АНАЛИЗ»

### 1. Загрузка изображения
- Открывается файл, определяется порядок осей, количество каналов.
- Извлекаются масштаб воксела и оптические параметры, необходимые для деконволюции.
- Если изображение больше 512 пикселей по любой стороне, оно автоматически уменьшается так, чтобы большая сторона стала ≤ 512 (это ускоряет работу). **Важно:** после даунсемплинга реальный масштаб воксела автоматически пересчитывается, чтобы измерения остались в верных физических единицах.

### 2. Определение каналов
- Открывается диалог выбора каналов с миниатюрами (MIP) всех каналов.
- Значения по умолчанию подставляются из метаданных: если программа уверенно определила канал DAPI (по имени, длине волны возбуждения или эмиссии), он будет предустановлен как DAPI, а оставшийся канал — как клетки. Если метаданных нет, по умолчанию предлагается канал 0 — клетки, канал 1 — DAPI.
- В диалоге можно переназначить роли каналов (Клетки / DAPI / Гранулы / Не включать в анализ) с помощью выпадающих списков под каждым каналом.
- Кнопка **«Применить»** фиксирует выбор. Кнопка **«Отмена»** использует значения по умолчанию без изменений.

### 3. Деконволюция (если включена)
- Применяется упрощённая деконволюция канала клеток (подавление фона через широкий размытый PSF, unsharp-маска, медианный фильтр).
- Применяется деконволюция канала DAPI (PSF рассчитывается по Airy-радиусу исходя из NA и длины волны эмиссии).
- Для обоих каналов предлагается диалог отбора срезов. Если в стеке после деконволюции есть явно мусорные по Z срезы (например, пустые в начале или в конце), их можно отключить для увеличения точности анализа. Деконволюированный стек сохраняется в папку deconvolved.

### 4. Разметка сом
- Открывается диалог с цветным MIP по Z (R = нижняя треть, G = средняя треть, B = верхняя треть).
- **Управление:**
  - **ЛКМ** — поставить точку сомы в этом XY (Z выбирается автоматически по максимуму сигнала в окне вокруг точки).
  - **Ctrl+ЛКМ** — удалить ближайшую поставленную точку.
  - **Shift+ЛКМ** — изменить тип ближайшей сомы (обычная / «бублик»).
  - **ПКМ** — открыть лупу (увеличенный Z-срез локально вокруг точки). В лупе слайдер Z листает срезы, ЛКМ ставит сому точно в выбранном XYZ, OK закрывает лупу.
  - Жёлтое перекрестье следует за курсором на MIP для точного наведения, координаты XY отображаются в левом верхнем углу.
- Нажатие **«Готово»** завершает разметку.
- После разметки появляется окно подтверждения: можно пролистать Z и проверить, что все точки стоят на нужных сомах и что все сомы оказались размечены.
- Нажатие **«Запустить сегментацию»** продолжает процесс.

### 5. Сегментация
- От каждой точки методом BFS-роста выращивается сома в 3D, ограниченная эллипсоидом вокруг центра. Границы сомы определяются по уровню интенсивности относительно начальной точки.
- В окрестности каждой сомы ищется ядро в DAPI-канале. Используется адаптивный порог (triangle threshold) + анализ персистентности для разделения слипшихся ядер. Если DAPI не используется, ядра не сегментируются.
- Применяется препроцессинг, зависящий от типа изображения (см. выше).
- На препроцессированном сигнале строится карта «структурности» (grain index / LoG).
- Пиксели с высокой структурностью попадают в маску роста.
- От каждой сомы запускается расчёт весовой карты по алгоритму Дейкстра, где стоимость перехода обратно пропорциональна яркости, структурности и нитевидности локальной структуры (с учётом штрафа за провалы яркости).
- Вокселы распределяются между сомами по принципу «связности с конкретной сомой» (каждая компонента связности присваивается той соме, с которой она соединена структурным путём). Отдельные компоненты без сом отбрасываются.

### 6. Ручная фильтрация (опционально)
- После сегментации открывается окно проверки качества для каждой структуры (сомы, ядра, клетки, гранулы).
- Если качество не устраивает, можно указать проблему:
  - **Слипшиеся клетки** — возврат к коррекции сом (добавить/удалить сомы).
  - **Артефакты** — возврат к удалению Z-срезов.
  - **Обрубленные отростки** — включение «мягкого» режима роста.
  - **Лишние объекты** — ручное удаление сегментов кликом.
- Если качество устраивает — просто нажмите «Да» и программа продолжит работу.

### 7. Измерения
- Для каждой клетки считаются 3D-объёмы (сомы, ядра, всей клетки), площади MIP-проекций, периметры, интенсивности, элонгация, солидность, ядерно-цитоплазматическое отношение. Отдельно оценивается количество отростков и их характеристики методом эллипсоидного сканирования.
- Результат сохраняется в {base}_measurements.csv и добавляется в общий all_measurements.csv.
- Если выбраны гранулы, для них считаются размеры, количество, форма и пространственное распределение.

### 8. Визуализации
- **3D-стеки:** исходный сигнал, DAPI, маски сом/ядер/клеток, RGB-маска клеток, overlay-стек (цветные маски поверх серого сигнала).
- **Мозаики срезов по Z в PNG:** сегментация сом, ядер, клеток.
- **Финальные MIP-визуализации:** цветные контуры клеток на сером фоне и на чёрном фоне.
- **Деконволюированные стеки с MIP-картинками.**

## VII. СТОЛБЦЫ В ФАЙЛАХ .CSV (sample_measurements.csv и all_measurements.csv)

- cell_id — номер клетки в данном файле
- filename — имя исходного файла
- centroid_x, centroid_y, centroid_z — координаты центра масс клетки (в пикселях/вокселях)
- cell_volume_um3 — объём всей клетки (сома + отростки), мкм³
- soma_volume_um3 — объём сомы, мкм³
- nucleus_volume_um3 — объём ядра, мкм³
- cytoplasm_volume_um3 — объём цитоплазмы, мкм³
- cell_surface_area_um2 — площадь поверхности клетки, мкм²
- cell_sphericity — сферичность клетки
- cell_solidity — солидность клетки
- soma_solidity — солидность сомы
- nucleus_solidity — солидность ядра
- cell_elongation_3d — элонгация (отношение главных осей тензора инерции) клетки
- cell_eccentricity — эксцентриситет
- cell_flatness — плоскостность
- cell_convexity_3d — выпуклость (3D)
- cell_extent_3d — заполненность bounding box (3D)
- cell_mean_intensity — средняя интенсивность сигнала клетки
- soma_mean_intensity — средняя интенсивность сигнала сомы
- nucleus_mean_intensity — средняя интенсивность сигнала ядра
- cytoplasm_mean_intensity — средняя интенсивность сигнала цитоплазмы
- nuclear_cytoplasmic_ratio — отношение объёма ядра к объёму цитоплазмы (если ядра нет, равно 0)
- cell_nucleus_intensity_ratio — отношение интенсивности ядра к цитоплазме
- cell_nucleus_centroid_distance_um — смещение центроида ядра от центроида клетки, мкм
- cell_soma_centroid_distance_um — смещение центроида сомы от центроида клетки, мкм
- process_max_count — максимальное число отростков, обнаруженных на каком-либо радиусе сканирования
- process_max_radius — радиус, при котором это число достигнуто
- cell_MIP_projection_perimeter_um — периметр проекции клетки, мкм
- cell_perimeter_um — периметр клетки, мкм (для 2D изображений)
- soma_perimeter_um — периметр сомы, мкм (для 2D изображений)
- nucleus_perimeter_um — периметр ядра, мкм (для 2D изображений)

**Гранулы (если выбраны):**
- granule_mean_intensity — средняя интенсивность гранул
- granule_count — количество гранул
- granule_mean_size_um3 — средний размер гранул, мкм³
- granule_volume_um3 — суммарный объём гранул, мкм³
- granule_volume_fraction — доля объёма гранул в объёме клетки
- granule_spatial_dispersion_um — пространственная дисперсия гранул, мкм
- granule_nearest_neighbor_mean_um — среднее расстояние до ближайшего соседа, мкм
- granule_clark_evans_index — индекс Кларка–Эванса
- granule_signal_to_background_ratio — SBR гранул

## VIII. ЧТО ДЕЛАТЬ ПРИ ПЛОХИХ РЕЗУЛЬТАТАХ

| Проблема | Решение |
| :--- | :--- |
| **Долго работает** | Уменьшите входной размер вручную. Отключите деконволюцию, если она не критична. |
| **Грязная сегментация** | Убедитесь, что выбран правильный *Тип изображения*. Попробуйте коррекцию фона в ImageJ. Удалите внефокусные срезы на этапе отбора. |
| **Клетки слипаются** | Включите ручную фильтрацию. Укажите на проблему «Нужно поправить сомы» и добавьте/удалите сомы. |
| **Отростки не доращиваются** | Включите ручную фильтрацию. Укажите на проблему «Нужно увеличить агрессивность роста». |
| **Неправильная привязка отростков** | Включите ручную фильтрацию. Используйте ручное удаление лишних сегментов. |
| **Ядра не сегментируются** | Убедитесь, что DAPI-канал правильно определён в диалоге выбора каналов. |
| **Файл не читается** | Проверьте, установлены ли nd2 (для .nd2), oirfile (для .oir), oiffile (для .oif), czifile (для .czi). |
