# ASTRO-ANALYZER v1.0.0

**ASTRO-ANALYZER** — это программа для автоматической сегментации и морфометрии астроцитов, нейронов и клеток микроглии на 3D-стеках и 2D-изображениях, полученных методами конфокальной и эпифлуоресцентной микроскопии (срезы ткани либо культура клеток). 

Результатом работы является таблица морфологических параметров каждой клетки: объём сомы, объём ядра, объём всей клетки с отростками, площади проекций, средние интенсивности, элонгация, ядерно-цитоплазматическое отношение, сложность ветвления отростков и многие другие признаки.

---

## I. ПАЙПЛАЙН

Для каждого входного файла (.tif / .nd2 / .czi / .lif / .ome.tif / .oir / .oif стек) программа выполняет следующие шаги:

1. Читает изображение и автоматически извлекает метаданные (масштаб XY и Z, количество и параметры каналов, оптические параметры). Предлагает пользователю диалог выбора каналов на основе автоматического анализа метаданных.
2. Проводит 3D-деконволюцию (если включено пользователем) для подавления внефокусного свечения.
3. Просит пользователя расставить центры сом на проекции максимальной интенсивности (MIP) или находит их автоматически (Beta).
4. Автоматически очерчивает сому каждой размеченной клетки в 3D.
5. Автоматически находит ядро каждой клетки в DAPI-канале (если включено пользователем).
6. Выращивает всю клетку (сома + отростки) в канале клеток.
7. Сегментирует гранулы внутри каждой клетки (если включено пользователем).
8. Даёт возможность вручную исправить или удалить проблемные клетки (если включена ручная фильтрация).
9. Считает морфологические параметры каждой клетки и сохраняет их в формате CSV.
10. Генерирует визуализации масок каждой клетки.
11. Складывает результаты из всех файлов данной папки в общий накопленный CSV (морфометрические параметры и количество клеток).

## III. ИНТЕРФЕЙС

Главное окно программы разделено на две части:

- **Слева — рабочая область.** В режиме настроек здесь отображается панель параметров. После запуска анализа здесь появляется протокол работы (лог). Между экраном настроек и логом можно свободно переключаться кнопками «← Настройки» (в логе) и «→ Вернуться к логу» (в настройках).
- **Справа — панель диалога.** Здесь появляются все всплывающие панели (выбор каналов, расстановка сом, ручная фильтрация и т.д.). Инструкции по работе с каждой панелью выводятся в нижней её части.

### Панель настроек включает следующие поля:

- **Файл/папка.** Интерактивный выбор файла или папки для анализа («Обзор…»).
- **Режим загрузки.** «Один файл» (для анализа одного стека / снимка) или «Папка» (для анализа папки с несколькими файлами).
- **Метаданные.** Кнопка «Прочитать из файла» пробегает по выбранному файлу и заполняет поля ниже (масштаб XY/Z, оптические параметры клеток и DAPI), если метаданные по какой-то причине не были извлечены автоматически. Если метаданных нет — поля остаются с дефолтами.
- **Тип клеток.** «Астроциты», «Микроглия» или «Нейроны». Влияет на имя выходной папки и отображаемое название в логе.
- **Тип изображения.** «Конфокальный» или «Эпифлуоресцентный». Определяет, какой препроцессинг будет применяться перед сегментацией (вычисление grain index для конфокального режима, LoG с гамма-коррекцией для эпифлуоресцентного режима).
- **Деконволюция.** Включает/выключает 3D-деконволюцию в протоколе препроцессинга.
- **XY (мкм/пиксель), Z (мкм/срез).** Определяют физический масштаб, от которого зависят все объёмные и линейные измерения.
- **Клетки: NA, λ, ε.** Параметры оптики для деконволюции канала клеток (числовая апертура, длина волны эмиссии, регуляризация Винера).
- **DAPI: NA, λ, ε.** Аналогичные параметры оптики для деконволюции канала DAPI (если используется).
- **Гранулы: NA, λ, ε.** Аналогичные параметры оптики для деконволюции канала гранул (если используется).
- **Автодетекция сом.** Включает автоматический поиск сом (данная функция пока находится в состоянии Beta-тестирования и работает неэффективно).
- **Ручная фильтрация клеток.** Включает запуск диалога ручной правки после автоматической сегментации.
- **Метрики…** Открывает окно выбора метрик, которые попадут в итоговый CSV-файл.

Для запуска анализа нажмите **«▶ Запустить анализ»**. Для выхода — **«Выход»**. Переключение языка (RU/EN) доступно в правом верхнем углу.

## IV. ПОРЯДОК РАБОТЫ

### 1. Загрузка и подготовка изображения
1. Нажмите «Обзор…» и выберите файл или папку. В идеальном случае метаданные (масштаб воксела и оптические параметры, необходимые для деконволюции) извлекутся из файла автоматически. Если метаданные в файле отсутствуют или неполные, программа использует значения по умолчанию, которые можно скорректировать вручную в панели настроек до запуска.
2. Назначьте в открывшемся автоматически диалоге с миниатюрами каналов те, которые требуется подвергнуть анализу (для клеток, ядер и внутриклеточных гранул), после чего нажмите **Применить**. 
3. Если метаданные на шаге 1 не подтянулись или подтянулись неправильно — нажмите «Прочитать из файла» или введите метаданные вручную.
4. Назначьте остальные параметры — убедитесь, что **Тип изображения** соответствует вашим данным и выберите **Тип клеток**.
5. Нажмите **▶ Запустить анализ**.
6. Если изображение имеет размер более 512 пикселей по любой стороне, программа отдельным диалогом предлагает уменьшить его так, чтобы большая сторона стала ≤ 512. Это значительно ускоряет работу. Если вы согласитесь, программа автоматически пересчитывает реальный масштаб воксела, чтобы все последующие измерения остались в верных физических единицах.
7. Если изображение имеет физический размер более 350 пикселей по любой стороне, программа отдельным диалогом предлагает произвести его ручную обрезку. Это значительно ускоряет работу. Если вы согласитесь, следующим диалогом выводится окно интерактивной обрезки. На проекции MIP вы можете выделить прямоугольную рамку или задать координаты X/Y, чтобы отсечь пустые края или артефакты по периферии снимка. Кнопка **Применить** обрезает стек по всем каналам. Кнопка **Пропустить** оставляет исходный размер.
8. Дождитесь, пока к каждому каналу применится деконволюция, для канала клеток и гранул — упрощенная (подавление фона через широкий размытый PSF, unsharp-маска, медианный фильтр), для канала DAPI — полная. После этого для всех каналов выведется отдельно диалог отбора срезов. Если в стеке после деконволюции есть явно мусорные по Z срезы (например, пустые в начале или в конце), их можно отключить для увеличения точности анализа.
9. В открывшемся диалоге с цветным MIP по Z (R = нижняя треть, G = средняя треть, B = верхняя треть) отметьте все сомы. Жёлтое перекрестье следует за курсором на MIP для точного наведения, координаты XY отображаются в левом верхнем углу. Нажатие **«Готово»** завершает разметку.  После разметки появляется окно подтверждения: можно пролистать Z и проверить, что все точки стоят на нужных сомах и что все сомы оказались размечены. Нажатие **«Запустить сегментацию»** продолжает процесс. **Управление:**
  - **ЛКМ** — поставить точку сомы в этом XY (Z выбирается автоматически по максимуму сигнала в окне вокруг точки).
  - **Ctrl+ЛКМ** — удалить ближайшую поставленную точку.
  - **Shift+ЛКМ** — изменить тип ближайшей сомы (обычная / «бублик»).
  - **ПКМ** — открыть лупу (увеличенный Z-срез локально вокруг точки). В лупе слайдер Z листает срезы, ЛКМ ставит сому точно в выбранном XYZ, OK закрывает лупу.

### 2. Сегментация
10. На следующем этапе от каждой точки автоматически выращивается сома в 3D, ограниченная эллипсоидом вокруг центра. Границы сомы определяются по уровню интенсивности относительно начальной точки. В окрестности каждой сомы ищется ядро в DAPI-канале с использованием адаптивного порог (triangle threshold) и анализа персистентности для разделения слипшихся ядер. Если DAPI не используется, ядра не сегментируются. Далее от каждой сомы запускается расчёт весовой карты по алгоритму Дейкстра, где стоимость перехода обратно пропорциональна яркости, структурности и нитевидности локальной структуры (с учётом штрафа за провалы яркости). На последнем этапе внутри маски каждой клетки по методу Otsu сегментируются гранулы (если соответствующая опция выбрана пользователем).
11. После каждого этапа сегментации открывается окно проверки качества для каждой структуры (сомы, ядра, клетки, гранулы). Если качество не устраивает, можно указать проблему:
  - **Слипшиеся клетки** — возврат к коррекции сом (добавить/удалить сомы).
  - **Артефакты** — возврат к удалению Z-срезов.
  - **Обрубленные отростки** — включение «мягкого» режима роста.
  - **Лишние объекты** — ручное удаление сегментов кликом.
- Если качество устраивает — просто нажмите «Да» и программа продолжит работу.
12. Для каждой клетки автоматически считаются 3D-объёмы (сомы, ядра, всей клетки), площади MIP-проекций, периметры, интенсивности, элонгация, солидность, ядерно-цитоплазматическое отношение. Отдельно оценивается количество отростков и их характеристики методом эллипсоидного сканирования. Если выбраны гранулы, для них считаются размеры, количество, форма и пространственное распределение.
13. Результат сохраняется в {base}_measurements.csv и добавляется в общий all_measurements.csv. Также строятся **визуализации**:
- **3D-стеки:** исходный сигнал, DAPI, маски сом/ядер/клеток, RGB-маска клеток, overlay-стек (цветные маски поверх серого сигнала).
- **Мозаики срезов по Z в PNG:** сегментация сом, ядер, клеток.
- **Финальные MIP-визуализации:** цветные контуры клеток на сером фоне и на чёрном фоне.
- **Деконволюированные стеки с MIP-картинками.**

## VI. СТОЛБЦЫ В ФАЙЛАХ .CSV (sample_measurements.csv и all_measurements.csv)

- cell_id — номер клетки в данном файле<br>
- filename — имя исходного файла<br>
- centroid_x, centroid_y, centroid_z — координаты центра масс клетки (в пикселях/вокселях)<br>
- cell_volume_um3 — объём всей клетки (сома + отростки), мкм³<br>
- soma_volume_um3 — объём сомы, мкм³<br>
- nucleus_volume_um3 — объём ядра, мкм³<br>
- cytoplasm_volume_um3 — объём цитоплазмы, мкм³<br>
- cell_surface_area_um2 — площадь поверхности клетки, мкм²<br>
- cell_sphericity — сферичность клетки<br>
- cell_solidity — солидность клетки<br>
- soma_solidity — солидность сомы<br>
- nucleus_solidity — солидность ядра<br>
- cell_elongation_3d — элонгация (отношение главных осей тензора инерции) клетки<br>
- cell_eccentricity — эксцентриситет<br>
- cell_flatness — плоскостность<br>
- cell_convexity_3d — выпуклость (3D)<br>
- cell_extent_3d — заполненность bounding box (3D)<br>
- cell_mean_intensity — средняя интенсивность сигнала клетки<br>
- soma_mean_intensity — средняя интенсивность сигнала сомы<br>
- nucleus_mean_intensity — средняя интенсивность сигнала ядра<br>
- cytoplasm_mean_intensity — средняя интенсивность сигнала цитоплазмы<br>
- nuclear_cytoplasmic_ratio — отношение объёма ядра к объёму цитоплазмы (если ядра нет, равно 0)<br>
- cell_nucleus_intensity_ratio — отношение интенсивности ядра к цитоплазме<br>
- cell_nucleus_centroid_distance_um — смещение центроида ядра от центроида клетки, мкм<br>
- cell_soma_centroid_distance_um — смещение центроида сомы от центроида клетки, мкм<br>
- process_max_count — максимальное число отростков, обнаруженных на каком-либо радиусе сканирования<br>
- process_max_radius — радиус, при котором это число достигнуто<br>
- cell_MIP_projection_perimeter_um — периметр проекции клетки, мкм<br>
- cell_perimeter_um — периметр клетки, мкм (для 2D изображений)<br>
- soma_perimeter_um — периметр сомы, мкм (для 2D изображений)<br>
- nucleus_perimeter_um — периметр ядра, мкм (для 2D изображений)<br>
- granule_mean_intensity — средняя интенсивность гранул<br>
- granule_count — количество гранул<br>
- granule_mean_size_um3 — средний размер гранул, мкм³<br>
- granule_volume_um3 — суммарный объём гранул, мкм³<br>
- granule_volume_fraction — доля объёма гранул в объёме клетки<br>
- granule_spatial_dispersion_um — пространственная дисперсия гранул, мкм<br>
- granule_nearest_neighbor_mean_um — среднее расстояние до ближайшего соседа, мкм<br>
- granule_clark_evans_index — индекс Кларка–Эванса<br>
- granule_signal_to_background_ratio — SBR гранул<br>

## VIII. ЧТО ДЕЛАТЬ ПРИ ПЛОХИХ РЕЗУЛЬТАТАХ

| Проблема | Решение |
| :--- | :--- |
| **Долго работает** | Уменьшите входной размер вручную. Включите даунсемплинг. Отключите деконволюцию, если она не критична. |
| **Грязная сегментация** | Убедитесь, что выбран правильный *Тип изображения*. Попробуйте коррекцию фона в ImageJ. Удалите внефокусные срезы на этапе отбора. |
| **Клетки слипаются** | Включите ручную фильтрацию. Укажите на проблему «Нужно поправить сомы» и добавьте/удалите сомы. |
| **Отростки не доращиваются** | Включите ручную фильтрацию. Укажите на проблему «Нужно увеличить агрессивность роста». |
| **Неправильная привязка отростков** | Включите ручную фильтрацию. Используйте ручное удаление лишних сегментов. |
| **Ядра не сегментируются** | Убедитесь, что DAPI-канал правильно определён в диалоге выбора каналов. |
| **Файл не читается** | Проверьте, установлены ли nd2 (для .nd2), oirfile (для .oir), oiffile (для .oif), czifile (для .czi). |
