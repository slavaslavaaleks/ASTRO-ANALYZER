ASTRO-ANALYZER v0.1.0-beta.1

Данная программа предназначена для автоматической сегментации и морфометрии астроцитов, нейронов и клеток микроглии на 3D-стеках и 2D-изображениях, полученных методами конфокальной и эпифлуоресцентной микроскопии (срезы ткани либо культура клеток). Результатом работы данной программы является таблица морфологических параметров каждой клетки: объём сомы, объём ядра, объём всей клетки с отростками, площади проекций, средние интенсивности, элонгация, ядерно-цитоплазматическое отношение, сложность ветвления отростков и другие признаки.

I. ПАЙПЛАЙН

Для каждого входного файла (.tif / .nd2 / .czi / .lif / .ome.tif / .oir / .oif stack) программа:

1. Читает изображение и метаданные (масштаб XY и Z, каналы, оптические параметры).
2. В случае наличия запроса пользователя проводит 3D-деконволюцию для подавления внефокусного свечения.
3. Просит пользователя расставить центры сом на проекции максимальной интенсивности.
4. Автоматически очерчивает сому каждой размеченной клетки в 3D.
5. Автоматически находит ядро каждой клетки в DAPI-канале.
6. Выращивает всю клетку (сома + отростки) в канале клеток.
7. Даёт возможность вручную исправить или удалить проблемные клетки.
8. Считает морфологические параметры каждой клетки и сохраняет в формате CSV.
9. Генерирует визуализации масок каждой клетки.
10. Складывает результаты из всех файлов данной папки в общий накопленный CSV.

II. УСТАНОВКА

Для корректной работы данной программы требуются Python 3.8+ и следующие пакеты:
pip install numpy pandas tifffile pillow matplotlib scipy scikit-image nd2 czifile oirfile oiffile readlif

Для запуска данной программы требуется запустить файл Astrocyte_analyzer_refactoring_GUI.py через команду python Astrocyte_analyzer_refactoring_GUI.py.

III. ИНТЕРФЕЙС

Главное окно данной программы разделено на две части:

- Слева — рабочая область. В режиме настроек здесь отображается панель параметров. После запуска анализа здесь появляется протокол работы (лог). Между экраном настроек и логом можно свободно переключаться кнопками «← Настройки» (в логе) и «→ Вернуться к логу» (в настройках).
- Справа — панель диалога. Здесь появляются все всплывающие панели (выбор каналов, расстановка сом, ручная фильтрация и т.д.). Инструкции по работе с каждой панелью выводятся в нижней ее части.

Панель настроек включает следующие поля:

- Файл/папка. Предлагает произвести интерактивный выбор файла или папки для анализа («Обзор...»)
- Режим загрузки. Предлагает произвести выбор режима работы — «Один файл» (для анализа одного стека / снимка) или «Папка» (для анализа папки с несколькими файлами)
- Метаданные. Кнопка «Прочитать из файла» пробегает по выбранному файлу и заполняет поля ниже (масштаб XY/Z, оптические параметры клеток и DAPI). Если метаданных нет — поля остаются с дефолтами.
- Тип клеток. Предлагает выбрать тип анализируемых клеток — «Астроциты», «Микроглия» или «Нейроны». Выбор того или иного пункта влияет на имя выходной папки и на отображаемое название в логе.
- Тип изображения. Предлагает выбрать способ получения изображения — «Конфокальный» или «Эпифлуоресцентный». Выбор того или иного пункта определяет, какой препроцессинг будет применяться перед сегментацией. При выборе пункта «Конфокальный» используется препроцессинг, основанный на вычислении многомасштабного grain index с нормировкой яркости по срезам (и подходящий для конфокальных изображений). При выборе пункта «Эпифлуоресцентный» используется LoG-препроцессинг с гамма-коррекцией, который убирает широкое диффузное гало и автофлуоресценцию (и подходит для эпифлуоресцентных изображений).
- Деконволюция. Определяет возможность включения в протокол препроцессинга 3D-деконволюции. Рекомендуется оставлять включённой для конфокальных стеков с заметным внефокусным свечением.
- XY (мкм/пиксель), Z (мкм/срез). Определяют физический масштаб, от которого зависят все объёмные и линейные измерения.
- Клетки: NA, λ, ε. Определяют параметры оптики для деконволюции канала клеток (числовая апертура, длина волны эмиссии, регуляризация Винера).
- DAPI: NA, λ, ε. Определяют параметры оптики для деконволюции канала DAPI.
- Ручная фильтрация клеток. Определяет возможность запуска диалога ручной правки после автоматической сегментации. Если выключено — программа сразу
переходит к измерениям.

Для запуска анализа требуется нажать на кнопку «▶ Запустить анализ» в нижней части экрана. Для выхода из интерфейса требуется нажать на кнопку «Выход» в нижней части экрана.

IV. ПОРЯДОК РАБОТЫ

1. Нажмите «Обзор...» и выберите файл или папку.
2. При необходимости нажмите «Прочитать из файла», чтобы подтянуть метаданные.
3. Убедитесь, что Тип изображения соответствует вашим данным
4. Выберите Тип клеток.
5. Оставьте остальные параметры по умолчанию либо настройте их вручную.
6. Нажмите на кнопку «▶ Запустить анализ».
7. Пройдите ручные диалоги (см. ниже).
8. По окончании работы смотрите результаты в папке <имя_файла>_<тип_клеток>_analysis/.

V. ЭТАПЫ ОБРАБОТКИ ФАЙЛА ПОСЛЕ НАЖАТИЯ КНОПКИ «▶ Запустить анализ»

1. Загрузка изображения
- Открывается файл, определяется порядок осей, количество каналов.
- Извлекаются масштаб воксела и оптические параметры, необходимые для деконволюции.
- Если изображение больше 512 пикселей по любой стороне, оно автоматически уменьшается так, чтобы большая сторона стала ≤ 512 (это ускоряет работу). Важно: после даунсемплинга реальный масштаб воксела автоматически пересчитывается, чтобы измерения остались в верных физических единицах.

2. Определение каналов
- Открывается диалог выбора каналов, в котором показаны миниатюры (MIP) всех каналов, найденных в файле. Значения по умолчанию в диалоге подставляются из метаданных изображения: если программа уверенно определила канал DAPI (по имени, длине волны возбуждения или эмиссии), он будет предустановлен как DAPI, а оставшийся канал — как клетки. Если метаданных нет или определить DAPI не удалось, по умолчанию предлагается канал 0 — клетки, канал 1 — DAPI. В диалоге можно переназначить каналы вручную:
  ЛКМ по изображению канала — назначить его каналом клеток.
  ПКМ по изображению канала — назначить его каналом DAPI.
  ЛКМ по нижней кнопке под каналом — включить/выключить канал из анализа.
  Галочка «Нет DAPI-канала» — отключить использование DAPI (ядра не будут сегментироваться).
- Кнопка «Применить» фиксирует выбор. Кнопка «Отмена» позволяет использовать значения по умолчанию без изменений.

3. Деконволюция (если включена)
- Применяется упрощённая деконволюция канала клеток (подавление фона через широкий размытый PSF, unsharp-маска, медианный фильтр)
- Применяется деконволюция канала DAPI (PSF рассчитывается по Airy-радиусу исходя из NA и длины волны эмиссии).
- Для обоих каналов предлагается диалог отбора срезов. Если в стеке, полученном после деконволюции, есть явно мусорные по Z срезы (например, пустые в начале или в конце), их можно отключить для увеличения точности анализа. Деконволюированный стек сохраняется в папку deconvolved.

4. Разметка сом
- Открывается диалог с цветным MIP по Z (R = нижняя треть, G = средняя треть, B = верхняя треть). В данном диалоге предлагается вручную расставить расположение центров клеток (сом). Небольшие вариации между операторами в расстановке сом не влияют на качество сегментации. Управление:
  ЛКМ — поставить точку сомы в этом XY (Z выбирается автоматически по максимуму сигнала в окне вокруг точки).
  Ctrl+ЛКМ — удалить ближайшую поставленную точку.
  ПКМ — открыть лупу (увеличенный Z-срез локально вокруг точки). В лупе слайдер Z листает срезы, ЛКМ ставит сому точно в выбранном XYZ, OK закрывает лупу.
  Жёлтое перекрестье следует за курсором на MIP для точного наведения, координаты XY отображаются в левом верхнем углу.
- Нажатие на кнопку «Готово» завершает разметку.
- После разметки появляется окно подтверждения: можно пролистать Z и проверить, что все точки стоят на нужных сомах и что все сомы оказались размечены. 
- Нажатие на кнопку «Запустить сегментацию» позволяет продолжить процесс.

5. Сегментация
- От каждой точки методом BFS-роста выращивается сома в 3D, ограниченная эллипсоидом вокруг центра. Границы сомы определяются по уровню интенсивности относительно начальной точки.
- В окрестности каждой сомы ищется ядро в DAPI-канале. Используется Otsu-порог по локальной области + watershed для разделения слипшихся ядер. Если DAPI не используется, ядра не сегментируются.
- Применяется препроцессинг, зависящий от типа изображения (см. выше).
- На препроцессированном сигнале строится карта «структурности» (grain index / LoG).
- Пиксели с высокой структурностью попадают в маску роста.
- От каждой сомы запускается расчет весовой карты по алгоритму Дейкстра по весовой карте, где стоимость перехода обратно пропорциональна яркости,
  структурности и нитевидности локальной структуре, в которую входит воксел (с учетом штрафа за провалы яркости).
- Вокселы распределяются между сомами по принципу «связности с конкретной сомой» (каждая компонента связности присваивается той соме, с которой она соединена структурным путём). Отдельные компоненты без сом отбрасываются.

6. Ручная фильтрация (опционально)

- Открывается MIP-карта всех найденных клеток с диалогом, позволяющим ресегментировать проблемные клетки. Управление:
  ЛКМ по клетке — отметить как НЕДОРОСТ (нужно дорастить отростки).
  ПКМ по клетке — отметить как ПЕРЕРОСТ (нужно сузить клетку).
- Кнопка «Продолжить» запускает пересегментацию выбранных клеток. Кнопка «Пропустить» позволяет пропустить фильтрацию.
- При пересегментации для каждой проблемной клетки применяется тот же алгоритм, что и в основной сегментации, но с иными параметрами.
- После пересегментации открывается диалог оценки, позволяющий принять решение по пересегментированным клеткам. Управление:
  ЛКМ по клетке — принять новую сегментацию (зелёный).
  ПКМ по клетке — удалить клетку (красный).
  Отсутствие клика (с нажатием кнопки «Продолжить») — откатить к старой сегментации.

7. Измерения
- Для каждой клетки считаются 3D-объёмы (сомы, ядра, всей клетки), площади MIP-проекций, периметры, интенсивности, элонгация, солидность, ядерно-цитоплазматическое отношение. Отдельно оценивается количество отростков и их характеристики методом эллипсоидного сканирования.
- Результат сохраняется в {base}_measurements.csv и добавляется в общий all_measurements.csv.

8. Визуализации
- 3D-стеки: исходный сигнал, DAPI, маски сом/ядер/клеток, RGB-маска клеток, overlay-стек (цветные маски поверх серого сигнала).
- Мозаики срезов по Z в PNG: сегментация сом, ядер, клеток.
- Финальные MIP-визуализации: цветные контуры клеток на сером фоне и на чёрном фоне.
- Деконволюированные стеки с MIP-картинками.

VII. СТОЛБЦЫ В ФАЙЛАХ .CSV (sample_measurements.csv и all_measurements.csv)

cell_id — номер клетки в данном файле
filename — имя исходного файла
centroid_x, centroid_y, centroid_z — координаты центра масс клетки (в пикселях/вокселях)
cell_volume_um3 — объём всей клетки (сома + отростки), мкм3
soma_volume_um3 — объём сомы, мкм3
nucleus_volume_um3 — объём ядра, мкм3
cell_area_um2 — площадь всей клетки, мкм2 (для 2D-изображений)
soma_area_um2 — площадь сомы, мкм2 (для 2D-изображений)
nucleus_area_um2 — площадь ядра, мкм2 (для 2D-изображений)
cell_solidity — солидность клетки (отношение площади к площади выпуклой оболочки)
soma_solidity — солидность сомы
nucleus_solidity — солидность ядра
elongation — элонгация (отношение главных осей тензора инерции) клетки
cell_mean_intensity — интенсивность сигнала клетки
soma_mean_intensity — интенсивность сигнала сомы
nucleus_mean_intensity — интенсивность сигнала ядра
nuclear_cytoplasmic_ratio — отношение объема ядра к объему цитоплазмы (если ядра нет, равно 0)
cell_MIP_projection_perimeter_um — периметр проекции клетки, мкм
soma_MIP_projection_perimeter_um — периметр проекции сомы, мкм
nucleus_MIP_projection_perimeter_um — периметр проекции ядра, мкм
cell_perimeter_um — периметр клетки, мкм (для 2D-изображений)
soma_perimeter_um — периметр сомы, мкм (для 2D-изображений)
nucleus_perimeter_um — периметр ядра, мкм (для 2D-изображений)
process_max_count — максимальное число отростков, обнаруженных на каком-либо радиусе сканирования
process_max_radius — радиус, при котором это число достигнуто
process_avg_mid — среднее число отростков в средней зоне радиусов
process_integral — интеграл профиля «число отростков vs радиус»
process_decay_ratio — отношение числа отростков на последнем радиусе к максимальному
process_branching_complexity — стандартное отклонение производной профиля (мера ветвления)
process_half_max_radius — радиус, на котором число отростков падает вдвое
process_avg_size — средний размер отростка (воксели)
process_total_voxels — общее число вокселей во всех отростках
process_to_cell_ratio — отношение объёма отростков к объёму клетки

VIII. ЧТО ДЕЛАТЬ ПРИ ПЛОХИХ РЕЗУЛЬТАТАХ

Долго работает:
- Уменьшите входной размер вручную
- Отключите деконволюцию, если она не критична.

Грязная сегментация:
- Убедитесь, что выбран правильный Тип изображения.
- Попробуйте осуществить коррекцию фона с помощью иных программ (ImageJ)
- Попробуйте удалить внефокусные срезы на этапе отбора срезов (особенно актуально для эпифлуоресцентных изображений)

Клетки слипаются:
- Используйте ручную фильтрацию (включив её в настройках). Отмечайте слипшиеся клетки как ПЕРЕРОСТ (ПКМ).

Отростки не доращиваются:
- Используйте ручную фильтрацию (включив её в настройках). Отмечайте такие клетки как НЕДОРОСТ (ЛКМ).

Неправильная привязка отростков к чужой клетке:
- Используйте ручную фильтрацию (включив её в настройках). Отметьте конфликтующие клетки как ПЕРЕРОСТ и НЕДОРОСТ соответственно.

Ядра не сегментируются
- Убедитесь, что DAPI-канал правильно определён в диалоге выбора каналов.

Файл не читается
- Проверьте, установлены ли nd2 (для .nd2) / oirfile (для .oir) / oiffile (для .oif) / czifile (для .czi).
